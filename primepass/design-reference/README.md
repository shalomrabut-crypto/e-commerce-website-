These are the approved design screens from the Prime Pass design canvas, as .dc.html source.
They use a design-canvas runtime (support.js) that is not included, so they will not run as-is.
Read them as a precise spec: markup, inline styles, the <style> animations, and the logic class at the bottom.
Images point to ../public/images/. ppqr.js is the QR encoder the mockups used; the real site uses the `qrcode` npm package.
